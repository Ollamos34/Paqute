Современный, быстрый и функциональный веб-мессенджер, построенный на базе **React**, **Vite** и **Supabase**. Приложение поддерживает обмен сообщениями в реальном времени, передачу файлов и вложений, многоязычность и гибкую кастомизацию интерфейса.

---

## ✨ Основные возможности

- ⚡ **Realtime-чат**: Мгновенная доставка и обновление сообщений с помощью Supabase Realtime Channels.
- 🟢 **Онлайн-статусы**: Отслеживание присутствия пользователей в сети в реальном времени.
- 📁 **Медиа и файлы**: Поддержка отправки изображений, видео, аудио и документов (до 25 МБ) с просмотром и скачиванием.
- 🔖 **Избранное («Сохраненное»)**: Личное пространство для быстрого сохранения важных заметок, файлов и сообщений.
- 💬 **Ответы и действия**: Быстрый ответ на конкретные сообщения, копирование, пересылка и удаление сообщений у всех.
- 🌐 **Мультиязычность**: Поддержка английского (`EN`), украинского (`UK`) и русского (`RU`) языков.
- 🎨 **Темы и кастомизация**: Переключение между светлой и тёмной темами, настройка фона чата и кастомных акцентных цветов.
- 🔒 **Управление чатами**: Возможность блокировки пользователей, отключения уведомлений (Mute), очистки и удаления диалогов.

---

## 🛠️ Технологический стек

- **Frontend**: React, Lucide React (иконки)
- **Сборщик**: Vite
- **Backend / Database**: Supabase (PostgreSQL, Authentication, Realtime, Storage)
- **Стилизация**: CSS3 (кастомные переменные для темизации)
